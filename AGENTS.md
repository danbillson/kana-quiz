# Agents

## Design

Styled with the dnbls design system. Follow the `dnbls-design` skill: tokens
live in `app/tokens.css` (a copy, keep it in sync with the skill), fonts in
`lib/fonts.ts`, shared class strings in `lib/styles.ts`.

## Components

Built on ui-sdk. Before using ui-sdk, follow the ui-sdk skill if it's
installed, and read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a new
component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading,
and read `rendering.md` next to it.
