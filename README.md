# pr-assets

Screenshots for pull request descriptions. Not code: this branch shares no
history with `main` and should never be merged.

One folder per PR (`pr-4/`, `pr-5/` …). Link images from a PR body with:

```markdown
![Alt text](https://raw.githubusercontent.com/danbillson/kana-quiz/pr-assets/pr-4/quiz-after.png)
```
